## What shipped today (8 commits, 85b1034 → 24d54da)

### Features
1. **Employee linking on Documents tab** — dropdown per document row to assign/unlink employees, filter by employee_id
2. **W-4/I-9 field extraction** — deterministic regex engine, SSN-safe (last 4 only), completeness scoring, expandable field panel in UI, auto-generates compliance insights
3. **Onboarding sub-tab** — 3 default templates (Engineering/Sales/Ops), per-employee instances, step checklists, auto-complete, stalled detection (>14 days), new HR tab position
4. **Apex → Instinct full rename** — 20 files migrated from direct localStorage reads to `@/lib/client-auth` canonical helpers. Zero remaining `apex_token` reads outside `client-auth.ts`
5. **Multi-carrier benefits parser** — Aetna, Cigna, UHC extractors with carrier-specific plan ID patterns, auto-fallback to BCBS parser. 9 new classifier rules.
6. **DB rename Phase 1** — Migration 014: 28 `instinct_*` views over `apex_*` tables
7. **Workspace setup wizard** — 4-step flow (workspace info → invite team → integrations → ready), dashboard welcome banner, workspace status API, team invite/accept APIs, migration 015

### Security hardening
- **Command injection fixed**: `execSync` → `execFileSync` with input validation in doc-generator.ts
- **JWT hardening**: production throws if secret missing or <32 chars
- **Login rate limiting**: 5 attempts/IP/5min with 429 + Retry-After
- **IDOR fixed**: ownership checks on docs/reports endpoints
- **Auth bypass fixed**: `getUserFromRequest` added to all 7 unauthenticated routes
- **Upload rate limiting**: 20/user/hour on documents, benefits, site assets
- **Error sanitization**: 19 API routes no longer leak `err.message`
- **Security headers middleware**: X-Content-Type-Options, X-Frame-Options, X-XSS-Protection, Referrer-Policy, Permissions-Policy, Content-Security-Policy
- **npm CVE fixed**: next@16.2.3 (GHSA-q4gf-8mx6-v5v3)
- **Automated CI workflow**: `.github/workflows/security-self-scan.yml` — 4-job pipeline (static scan, pentest validation, dependency audit, summary)

### Analytics
- 20+ new event types across all features
- All tracked via `trackEvent()` + triple-write
- Full onboarding funnel tracking (setup_started → step_completed → completed)
