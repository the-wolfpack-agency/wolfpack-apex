## Headline

**Platform renamed: Wolfpack Apex → Wolfpack Instinct.** "Wolfpack Assistant" is the chat feature; "Wolfpack Instinct" is the platform. Internal code names (apex_*, ApexEvent, etc.) intentionally left alone per rename rules.

Two major integrations landed end-to-end: **QuickBooks Online** (financials) and **Microsoft Graph** (calendar/email/contacts → Morning Briefing). New **CEO role** added above CTO for business-data access. All demo/shadow data purged from the dashboard when integrations aren't connected — users now see connect prompts instead of fake numbers.

## Architecture Updates

### New Roles (4 → 4, but reranked)
| Role | Level | Access |
|---|---|---|
| **CEO** | top | All business data (QuickBooks financials, MS Graph), no code writes |
| **CTO** | top | All technical data, no code writes from dashboard |
| dev | mid | Code, knowledge, assistant |
| sales / ops | base | Knowledge, assistant, journal |

### New Pages
- `/financials` — P&L, balance sheet, AR/AP aging, invoices (CEO only)
- `/settings` — Integrations: connect Microsoft 365 + QuickBooks
- `/briefing` — Morning Briefing (calendar + email + action items)

Codebase Explorer removed.

### New Integrations
| Integration | OAuth2 | What it pulls |
|---|---|---|
| QuickBooks Online | yes | P&L, balance sheet, AR, AP, invoices |
| Microsoft Graph | yes | Calendar, email, contacts |

### Connection-Aware Rendering
Every integration-backed widget now checks `isConnected` first. If false, renders a connect prompt — never shadow data. Applies to dashboard, briefing, financials, action items.
