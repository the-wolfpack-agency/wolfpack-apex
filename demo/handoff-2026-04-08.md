## Known categories the HR Documents classifier handles

Drop any of these on the HR **Documents** tab (or **Benefits** tab — smart router handles wrong-tab drops gracefully):

| Category | Triggers on |
|---|---|
| `w4` | "Form W-4" + "Employee's Withholding Certificate" + "Multiple Jobs Worksheet" |
| `i9` | "Form I-9" + "Employment Eligibility Verification" + "USCIS" + "List A/B/C" |
| `benefits_renewal` | "Medical Plans" + "Renewal Effective Date" + "Total Monthly Medical Cost" + plan-id+price patterns |
| `benefits_enrollment` | "Group Enrollment Application" / "Solicitud de cobertura" + "Declination of Coverage" + "PCP Selection" + "BCBSTX" |
| `offer_letter` | "Offer of Employment" + "annual salary" + "at-will employment" + "start date" |
| `handbook` | "Employee Handbook" + "Code of Conduct" + "PTO Policy" + "Anti-Harassment" |
| `unclassified` | falls below 0.4 confidence threshold; user can re-categorize via dropdown |

Adding a new doc type = push a few `{ category, signature, weight, reason }` rules into `RULES` in `src/lib/hr-documents.ts` + add a unit test fixture. Zero AI tokens.

## Demo-blocker env vars (HARD BLOCKER for Sites only)

Sites cannot call GitHub until these are set in **Vercel project env vars** for `wolfpack-instinct`:

1. **`GITHUB_TOKEN_WOLFPACK_AGENCY`** — classic PAT with `repo` + `workflow` scopes (or fine-grained PAT scoped to `the-wolfpack-agency` org with Contents r/w, Administration r/w, Actions r/w, Metadata r). Without this, "Generate preview" returns "GITHUB_TOKEN_WOLFPACK_AGENCY not set — refusing to call GitHub API in dev".

2. **`WOLFPACK_SITES_WEBHOOK_SECRET`** — random string. Generate via `openssl rand -hex 32`. Also set as a repository secret with the same name in `the-wolfpack-agency/wolfpack-site-template` so the canary workflow can POST deploy results back to Instinct.

3. **`INSTINCT_WEBHOOK_URL`** — `https://wolfpack-instinct.vercel.app/api/sites/webhook` — set as a repository secret in the template repo (NOT in Instinct itself).

**HR feature requires zero env vars** — fully self-contained, demo-safe by design.

## Things to NOT touch unless you have a reason

- **`outputFileTracingRoot` in `next.config.ts`** — pinned to fix Vercel bundling unpdf incorrectly. Removing this brings back "This page couldn't load" on /api/people/benefits.
- **`serverExternalPackages: ["unpdf"]`** — same reason.
- **`runtime = "nodejs"` on `/api/people/benefits` and `/api/people/documents`** — pdf parsing needs Node Buffer + fs APIs not present on Edge.
- **Login writing both `instinct_token` AND `apex_token`** — keeps backwards compat. Don't remove until every callsite is migrated.
- **`getBenefitDocument()` numeric coercion loop** — Postgres NUMERIC columns come back as strings via node-postgres. Removing the coercion crashes the parsed plans table render.
