## Three things to know

1. **HTML rendering goes through `@/lib/html-sanitize` always.** It's a DOMPurify wrapper. Any new email-rendering / user-content-display surface must use it; regex-based stripping is a CodeQL high-finding magnet (we cleaned up 23 of those this session).

2. **Logging user input goes through `@/lib/log-sanitize`'s `sanitizeForLog()`.** Strips `\r\n\t` + control chars + caps at 200 chars. Catches log-injection findings before they ship.

3. **Automation dedup is now message-id-first.** `dedup.ts` exports `computeDedupKey(message)` which prefers RFC-5322 `internetMessageId` (lowercased, brackets stripped) and falls back to `sha256(subject|from|received_iso|first512bytes)`. Migration 130 added the unique index. Don't bypass this — false-positive duplicates were the #1 user complaint pre-fix.
