## What Was Built Today

### Wolfpack Instinct — Team Intelligence Platform

Built from scratch in one session. Hosted web app for the Wolfpack Agency team connecting people, AI, and codebase into a compounding knowledge system.

### Architecture

| Store | Purpose | Cost |
|---|---|---|
| **PostgreSQL** | Structured data, conversations, user memory, analytics | Free reads |
| **Qdrant** | Semantic search for similar past questions/answers | Free reads |
| **Neo4j** | Knowledge graph, collaboration patterns, relationships | Free reads |
| **Claude API** | Last-resort fallback when above 3 can't answer | Tokens (cached after first use) |

### Assistant — Persistent Memory Architecture

| Layer | What It Stores | Persistence |
|---|---|---|
| **User Memory** | Role, preferences, expertise topics, instructions | DB (apex_user_memory) |
| **Conversation Memory** | Full message history, summaries, auto-resume | DB (apex_conversations + apex_messages) |
| **Organizational Memory** | Cached Q&A, codebase docs, client context | DB (apex_knowledge) + Qdrant vectors |
| **Analytics Memory** | Response quality, gaps, efficiency trends | DB (apex_events) + learning views |

Users never come back to a clueless agent. Conversations persist, user context carries over, and the knowledge base compounds with every interaction.

### Modular Chat Component

`<ApexChat />` is a standalone, embeddable component:
```tsx
<ApexChat
  pageContext="User is on the reports page"
  contextData={{ currentClient: "Acme Motors" }}
  position="inline"    // or "floating" for bottom-right bubble
  showHistory={true}
  showSource={true}
  showRating={true}
/>
```

Can be embedded on any page with page-specific context injected automatically.

### Data Flow Tests (52 tests verify full pipeline)

Every message is traced: prompt → PG insert → Qdrant vector → Neo4j graph → response stored → analytics tracked. Tests verify data actually lands in stores (not just that functions were called).

### AI Integration

- Uses Wolfpack Agency organization Claude API key (ANTHROPIC_API_KEY)
- Currently building/testing without key (all AI paths gracefully fall back)
- When key arrives: set in Vercel, AI features activate immediately
- Every AI response cached in knowledge base → second ask is free
- All AI output cleaned of em dashes and AI-tell words via cleanAiArtifacts()
- No AI provider branding anywhere in UI

## Known Limitations

1. **Codebase browser** — needs filesystem access, won't work on Vercel. Future: index codebase into knowledge base during CI step.
2. **AI features** — waiting on org Claude API key. All paths fall back gracefully.
3. **Knowledge base** — empty until docs are loaded. Zero-token retrieval works once data exists.
4. **Real-time data** — shadow mode (demo data) until DATABASE_URL is set.
