## What Was Built Today

### Wolfpack Apex — Team Intelligence Platform

Built from scratch in one session. A hosted web app for the Wolfpack Agency team that connects people, AI, and codebase into a compounding knowledge system.

### Architecture

| Layer | What It Does |
|---|---|
| **Knowledge** (Qdrant) | Question/answer embeddings, semantic search, cached responses |
| **Graph** (Neo4j) | Who asked what, collaboration patterns, question-to-doc pipelines |
| **Structured** (PostgreSQL) | Team members, events, journals, features, discussions, docs, clients |
| **Learning Views** | Knowledge gaps, AI efficiency, team expertise, automation ROI, discussion velocity |

### Key Design Decisions

- **Zero-token-first**: Knowledge base, codebase search, and analytics data are always checked before AI. AI responses are cached for free future retrieval.
- **No AI branding**: The assistant is "Apex Assistant" — no Claude, ChatGPT, or provider names visible to users.
- **AI artifact cleanup**: All generated content passes through `cleanAiArtifacts()` which strips em dashes, "leverage", "utilize", "delve", etc.
- **Role-based views**: CTO sees everything. Dev sees code + prototypes. Sales sees clients + proposals. Ops sees processes + journals.
- **Triple-write**: Every knowledge entry and analytics event writes to PG + Qdrant + Neo4j.
- **Wolfpack Agency branding**: Gold #f1c233, dark #212124, Lexend Peta + Ubuntu Mono, real logo from thewolfpack.agency.

### Data Flow

```
Team member asks question or takes action
  → trackEvent() → PG analytics_events + Qdrant + Neo4j
  → Search knowledge base (zero tokens)
  → If not found: search codebase (zero tokens)
  → If not found: search analytics (zero tokens)
  → If still not found: call AI → cache result → next time is free
  → Learning views compound: gaps, efficiency, expertise, velocity
```
