## Things that bit us today (tribal knowledge)
- `apex_integrations` does NOT exist under any name. Integrations are per-provider (`instinct_ms_tokens`, `instinct_qbo_tokens`, `instinct_plaud_connections`).
- `safeQuery` returns empty rows on "relation does not exist" (shadow-mode posture). Means typos in table names silently pass under-test and fail at runtime — ALWAYS grep for the actual CREATE TABLE before trusting a status route.
- MS Graph `bodyPreview` contains Teams invite boilerplate + quoted-reply headers verbatim. Never render it raw.
- Vercel serverless rate-limit counters are per-container, so a redeploy flushes them. Useful recovery lever.
- `fetchWithRefresh(url, { method: "POST", headers: authHeaders() })` with no body hits any `req.json()` server and 500s. Explicit empty body or JSON body needed.
