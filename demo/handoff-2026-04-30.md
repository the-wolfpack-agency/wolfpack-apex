## Architecture decisions worth remembering

- **`src/lib/qr/origin.ts`** is the canonical helper for "where am I publicly?" — every new feature that emits public URLs should use it instead of stitching `NEXT_PUBLIC_BASE_URL` checks inline. Resolution: `NEXT_PUBLIC_BASE_URL` → `VERCEL_PROJECT_PRODUCTION_URL` → `VERCEL_BRANCH_URL` → `VERCEL_URL` (last resort) → request origin.
- **Org-wide assistant cache + learning loop**: every Q/A across the entire org is reusable; corrections become facts injected into future prompts. Single-tenant deployment so no cross-tenant scope concerns. Fuzzy match via token-set Jaccard ≥ 0.8.
- **Bulletin notes are org-shared by default** — every wolfpack member sees every board. `owner_user_id` is recorded for audit but NOT used to scope reads. Same approach as `instinct_meeting_transcripts`.
- **Hand-rolled PDF generation** (`src/app/(dashboard)/qr/download.ts`): single-page Letter, JPEG embed via /DCTDecode, ~150 LOC, no jspdf dep.
- **Route + lib double-validation is a bug magnet.** The bulletin empty-body fix had to be applied at BOTH layers because the route test mocked the lib. Rule going forward: when a route test mocks the lib, ALSO add an unmocked lib test for the same input contract.
- **Transformed ancestors break `position: fixed` containment.** The bulletin sticky note's `transform: rotate()` made the inline assoc picker tilt with it, even with `position: fixed`. Fix: portal to `document.body` via `react-dom/createPortal`. Pattern to remember whenever a fixed-position child of a transformed parent needs to escape.
