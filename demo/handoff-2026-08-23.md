## Conversational Context (the part that matters tomorrow)

**The standing blocker is gone.** Until today nothing in the routine arc had been
verified on wolfpack-instinct.vercel.app while signed in. It now is: 17 specs
green against production, including the five-role sweep.

**Accounts that now exist in production.** Five non-admin role accounts sharing
one password (`ADMIN_E2E_PASSWORD`), and one admin account for the smoke suite
(`SMOKE_TEST_*`). They are separate on purpose: the dangerous credential is one
revocable thing rather than a property of the whole set.

    UPDATE instinct_team_members SET is_active = false WHERE email LIKE 'e2e%@thewolfpack.agency';

The admin one exists because the smoke suite probes /admin/audit, which is
ceo/cto/evp only. There is no narrower option: evp is defined as = CEO. That
credential is readable by any workflow anybody with repo write can push. It was
already true before today; it is written down now so it is a decision rather
than an inherited default.

**A mistake worth remembering.** I overwrote SMOKE_TEST_EMAIL before checking
what consumed it, which silently removed admin coverage from the smoke suite,
and GitHub secrets cannot be read back so the old value was unrecoverable. Check
what consumes a secret before rotating it.

**Four bugs the real access found, and the pattern behind two of them.**

1. The dashboard's release-gate banner asked an admin endpoint on every load.
2. The financials card did the same with QuickBooks, in six call sites.

Both handled the refusal correctly and rendered nothing, so nothing looked
broken. A component that discovers its own audience from a 403 asks everybody.
There is now one helper, `canI()` in lib/client-capabilities, and a guard test
that accepts only that spelling.

3. "run my morning" reported a MONTH of calendar events as though they were
   today, because the step said today and calendar_widget returns a month grid.
   One tool answering a question the step had not asked. Worth sweeping the rest
   of the catalogue for that shape.
4. Redaction mangled Microsoft Graph meeting ids by matching the generic
   40-plus-base64 key rule. Reported as a key leak; it was the opposite, the
   placeholder was the gate working. Narrow exemption added.

**A near miss.** The per-role sweep first failed all five roles on 401
POST /api/analytics, which read like the learning loop losing data for every
non-admin. It is the token refresh handshake working as designed. A 401 now
counts only when nothing to that path afterwards succeeded; 403 is the real
signal because no retry changes it.

**Direction the CTO set today**, not yet built: read a person's schedule,
meeting load and workload to suggest how their day could go better, and over
time discover which of their tools are not connected to us. The honest
foundation for the second half already exists and is collecting data:
plan_my_day records every described step with no tool behind it, and
routine_templates records what a workspace is shown and cannot use. Build the
efficiency read on those counts rather than on a model's opinion of a calendar.

  back to 2026-08-19, and the failure is at the workflow level: zero jobs are
