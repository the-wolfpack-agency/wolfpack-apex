## Known Blockers

- **HARD BLOCKER — Instinct's Vercel env vars**: `VERCEL_TOKEN_WOLFPACK_AGENCY`,
  `VERCEL_ORG_ID`, and `WOLFPACK_SITES_WEBHOOK_SECRET` must be set on
  Instinct's Vercel project before any Sites deploy can succeed.
  Without them the new preflight (8b7ad91) correctly fails fast with
  an actionable error. User must set these before demoing Sites on
  Monday. Self-heal in the same commit means existing stuck repos
  (like wolfpack-test4) will be auto-healed on the next deploy
  attempt once the env is populated.
- **GitHub PAT scope**: needs `Secrets: Read and write` so
  `provisionClientRepoSecrets` can seal + PUT the five Actions
  secrets. Currently the PAT may only have `repo + workflow` scope.
- **ANTHROPIC_API_KEY** on Instinct's Vercel env — required for the
  prompt editor's brief-edit AI. Without it, POST /api/sites/:id/brief-edit
  returns 503 `ai_not_configured` (surfaced as an actionable banner).
